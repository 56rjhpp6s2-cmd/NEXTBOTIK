BELOW / ZERO — ИГРА С ДРУГОМ

1. Полностью распакуйте ZIP в удобную папку. Не запускайте прямо внутри архива.
2. Откройте папку BELOW_ZERO и дважды нажмите PLAY.cmd.
   Godot уже внутри: устанавливать редактор или скачивать движок не нужно.
   Файлы PLAY.cmd, BELOW_ZERO.pck и папка runtime должны лежать вместе.
3. В Radmin VPN подключитесь к одной сети. Если сети нет, один создаёт её,
   второй входит по её названию и паролю.
4. Хост выбирает режим ENDLESS или BOSSFIGHT, затем нажимает
   СЕТЬ / RADMIN VPN → СОЗДАТЬ СЕРВЕР. В Endless также выбирается карта;
   у Bossfight свои карты Dust Quarter и Sun Ring.
5. Друг выбирает СЕТЬ / RADMIN VPN, вводит IP ХОСТА ИЗ RADMIN VPN,
   порт 24577 и нажимает ПОДКЛЮЧИТЬСЯ. IP вводится отдельно от порта.
6. При запросе брандмауэра Windows разрешите сетевой доступ игре.

Оба играйте из одной версии этого архива. IP 127.0.0.1 подходит только
для двух экземпляров на одном ПК; другу нужен IP компьютера хоста из Radmin.

Все три обычных лица некстботов, две фотографии босса, фотография Reward Keeper
с поднятыми руками, PNG «Без имени.png», пробирка, учебник литературы и
Конституция уже встроены в игру. Пробирка наносит урон Елене Финкельштейн,
учебник литературы — Коган на розовом фоне, Конституция — чёрно-белому лицу.
Неправильный предмет не наносит урон и показывает нужную уязвимость.
На первом запуске выбрана «Без имени.png», размер броска — 1,3 метра.
Повторно импортировать картинки не требуется. Новые картинки тоже можно
импортировать; выбор сохраняется на этом компьютере.

WASD — движение и стрейфы в воздухе; мышь — обзор; Shift — бег без стамины.
Ctrl — присесть, во время бега — скольжение; Space — прыжок, в том числе из скольжения.
F4 — спидометр; в настройках есть автобхоп, переключение приседа/бега и эффекты камеры.
ЛКМ — бросить PNG; ПКМ — прицел; колесо — смена PNG; R — обновить список.
Tab — библиотека PNG; E — взаимодействие; F — фонарь; Escape — меню.
В сетевой игре меню не останавливает врагов. Каждый игрок возрождается
отдельно. После выхода вся группа переходит глубже: уровни 1–3 используют
выбранную карту, а с уровня 4 каждый раз строится новый общий лабиринт.
В Bossfight у всех одинаковые случайные переключатели. Каждый четвёртый
уровень — общая арена с боссом: сначала 4000 HP, затем +500 HP за цикл.
После его смерти появляется Reward Keeper с двумя наградами в руках.
Q сразу выбирает левую награду, E — правую. Целиться и подходить не нужно.
Через 20 секунд выбранная большинством награда выдаётся всей группе один раз.
Только после этого позади NPC появляется общий рычаг: нажмите E, чтобы вся
группа синхронно перешла на следующий уровень. Пропустить награду нельзя.

Если нет соединения: проверьте IP, одинаковый порт, одну сеть Radmin VPN,
запущенный сервер и разрешение игры в брандмауэре. Через меню Radmin VPN
можно проверить Ping до компьютера хоста.
Официальная помощь: https://www.radmin-vpn.com/help/

Этот комплект можно перенести в другую папку. Пути к компьютеру автора
для запуска не используются. Личные настройки и рекорды каждого игрока
хранятся отдельно в профиле Windows.
